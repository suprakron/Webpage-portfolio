Web Quiz

ระบบเกมควิซเพื่อการเรียนรู้

This project aims to develop a quiz system based on Bloom's learning theory for use during classroom instruction. Teachers can manage subjects, create, delete, and edit quizzes, including multiple-choice questions (2–4 options) and fill-in-the-blank questions with images. Students can access and complete quizzes to facilitate real-time learning assessment.
